Engine behavior contract (research Pattern 3 — the per-segment loop the GREEN task implements):
1. NoChord segment -> continue (zero notes, every slot).
2. Tone set: `toneSetIntervals(archetype.toneSet, segment.chord.quality, archetype.dropRoot)`.
3. Register: base root = `rootMidiNote(segment.chord.pitchClass, archetype.registerAnchor)` + seed-selected `octaveOffsetPool[seedOctave % size]`. If `archetype.useVoiceLeading`: run pitches through VoiceLeadingEngine's existing nearestOctaveNote mechanism against the previous segment's voiced pitches, clamped to [registerLow, registerHigh] (Phase 5 R&B mechanism — read VoiceLeadingEngine.h + the retired generateRnbNeoSoulRow for the exact call shape first).
4. Rhythm: `variant = rhythmPool[seedRhythm % size]`; onsets = tileOnsets(...) offset by the segment's row-relative start beat; note length = variant.noteLengthRatio * (gap to next onset, or to segment end for the last).
5. Velocity: `baseVelocity * accentPattern[onsetIndex % size] + deterministicJitter(runningNoteIndex, seed, jitterRange)`, clamped to [0.05, 1.0].
6. StabArp slot: when the tone set has >1 tone, Arpeggiator::arpeggiate(pitches, Up, onsetCount) distributes ONE tone per onset (arp, not block hits).
7. TopLineMotif only: per-onset hash(seed, segmentIndex, onsetIndex) thresholded against ornamentProbability inserts ONE diatonic passing tone from diatonicScaleIntervals(result.key.isMajor) anchored at result.key.tonicPitchClass — the ONLY non-chord-tone path, still key-diatonic.
8. BassLine slot with non-empty bassRhythmPool: delegate to `generateBassRow(result, bassRhythmPool[seedRhythm % size])`, then apply octave offset + velocity reshaping to the returned notes.
Seed usage: derive independent sub-seeds from the one uint32_t (seedRhythm = seed; seedOctave = seed * 0x9e3779b9u ^ 0x85ebca6bu; per-note ornament hash) — document each. The seed NEVER indexes into result.chords and NEVER reads/modifies pitchClass/quality (Pitfall A).
