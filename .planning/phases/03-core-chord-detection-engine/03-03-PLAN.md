1. Input is already 8 kHz mono (from AudioPreprocessing — do not resample here).
2. STFT: 256-sample window (32 ms), 32-sample hop (4 ms) → envelope rate 250 Hz. Use `juce::dsp::FFT` order 8 and `juce::dsp::WindowingFunction<float>` (hann, normalise=true); call `performFrequencyOnlyForwardTransform` for magnitudes (129 non-negative bins).
3. Map magnitudes to 40 mel bands over 0–4000 Hz with triangular weights (standard HTK mel: m = 2595·log10(1 + f/700); build the filterbank once).
4. Convert to dB: 20·log10(max(band, 1e-10)).
5. First-order difference along time per band; half-wave rectify; sum across the 40 bands.
6. High-pass ≈0.4 Hz to make locally zero-mean: a first-order one-pole HP at the 250 Hz envelope rate is sufficient (named constant kEnvelopeHighPassHz = 0.4).
7. Smooth with a ~20 ms Gaussian kernel (σ ≈ 5 envelope frames; named constant, tunable).
8. Normalize by dividing by the envelope's own standard deviation (guard σ≈0 → leave zeros).
Guard degenerate input: fewer samples than one window → empty envelope, no crash.

- Apply perceptual weighting `W(τ) = exp(-0.5·(log2(τ/τ0)/στ)²)` with τ0 = 0.5 s (120 BPM) and στ = 1.4 octaves (named constants — the paper's own tuned values) → `TPS(τ)`.

- Port the `dpBeatTrack` reference implementation from 03-RESEARCH.md "Code Examples" (Ellis Fig. 1 port): search window τ ∈ [t−2τp, t−τp/2], transition penalty F(Δt,τ) = −(log(Δt/τ))², cumulative-score recursion, backtrace from max final score.
