Template construction (03-RESEARCH.md "Code Examples" — use, but ChordQuality comes from AnalysisResult.h, do NOT re-declare the enum):
- Major: {r, r+4, r+7}; Minor: {r, r+3, r+7}; Dom7: {r, r+4, r+7, r+10} (mod 12), binary, L2-normalized.

Scoring formula (03-RESEARCH.md, project synthesis to validate empirically):
`rawScore(c) = cosine(harmonicAvg, template_c) + γ · bassAvg[root(c)] / (Σ bassAvg + ε)`, then L1-normalize the 36 scores per beat → observation matrix B.

Viterbi: uniform initial prior 1/36; A(i,i) = β, A(i,j) = (1-β)/35; log-domain; β = 0.85 starting point.
