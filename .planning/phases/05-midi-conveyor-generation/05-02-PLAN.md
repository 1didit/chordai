Timing domain: NoteEvent.startBeats = (double) segment.startBeatIndex + patternOffset; lengths in beats.
NEVER derive timing from startSeconds/bpm (anti-pattern — float rounding at the EXP-03 boundary).
Rhythm is segment-relative (Pattern 3): patterns restart at each segment's own start, not the global bar grid.
Every per-segment loop starts with `if (segment.chord.quality == ChordQuality::NoChord) continue;` (Pitfall 1).
Velocity: `juce::jlimit (0.0f, 1.0f, base + deterministicJitter (noteIndex, seed, range))` where noteIndex is a
running uint32_t counter across all NoteEvents emitted by THAT generator call (starts at 0 each call — determinism).

Test naming: `TEST_CASE ("StyleVoicingTests.CaseName", "[stylevoicing]")`.
