# ChordAI

## What This Is

Аудіоплагін (VST3/AU) та standalone-додаток для продюсерів і бітмейкерів: працює як конвеєр — з одного боку "заїжджає" пісня (файл цілком або вибраний відрізок), з іншого виходить кілька рядків готових MIDI-наборів — акордові прогресії у схожому стилі в різних voicing-варіантах (+ бас-лінія), які перетягуються мишкою прямо в piano roll DAW. Комерційний продукт для релізу.

## Core Value

Продюсер закидає пісню-референс і за секунди отримує кілька готових до використання MIDI-акордових наборів у схожому стилі — без знання теорії музики і без ручного підбору на слух.

### Active

- [ ] Імпорт аудіофайлу (WAV/MP3/AIFF/FLAC) через drag-and-drop у вікно плагіна/додатка
- [ ] Відображення waveform і вибір відрізка для аналізу (або вся пісня)
- [ ] Автоматичне визначення тональності й темпу джерела
- [ ] Розпізнавання акордової прогресії (chromagram + Viterbi-згладжування), прив'язка до сітки тактів
- [ ] Конвеєрний вивід: кілька рядків MIDI-наборів одночасно — детектована прогресія as-is + стильові варіації (voicing-пресети) + бас-лінія
- [ ] Voicing-стилі v1: Pop/Hip-hop/Trap (тріади, dark minor), R&B/Neo-soul (7th/9th/11th, плавне голосоведення), Electronic/House (stab-и, ритмічні патерни)
- [ ] Drag-and-drop будь-якого MIDI-рядка з плагіна прямо в piano roll DAW
- [ ] Експорт у .mid файл
- [ ] Збірки: VST3, AU, Standalone (macOS); перевірено в Ableton Live, FL Studio, Logic Pro

### Out of Scope

- Windows-збірка — потрібна для комерційного релізу, але v1 розробляється і стабілізується на macOS; крос-платформа після валідації ядра
- Запис аудіо з треку DAW у реальному часі (кнопка Listen) — v2; у v1 тільки файл drag-and-drop
- ML-модель розпізнавання (ONNX) — v2; v1 на класичному DSP, але архітектура аналізатора закладається зі змінним бекендом
- Транскрипція мелодії/вокалу — інша задача, не акорди
- Stem separation (виділення інструментів) — важка залежність; хромаграма працює по повному міксу
- Ліцензування/копі-протекція та інсталятор з підписом — потрібні до релізу, але після робочого MVP

## Context

- Ринок: інструменти типу Scaler 2, Chord Prism, Captain Chords — але конвеєрний UX "пісня → кілька готових MIDI-наборів" як основний сценарій відрізняє продукт
- Цільова аудиторія: бітмейкери/продюсери без глибокої теорії музики (pop/hip-hop/trap, R&B/neo-soul, EDM)
- Аналіз повністю локальний (офлайн), без хмарних сервісів — плагін має працювати в студії без інтернету
- Розробка на macOS (Darwin), основна машина користувача
- Робоча назва: ChordAI (може змінитися до релізу)

## Constraints

- **Tech stack**: JUCE 8, C++20, CMake — один код для VST3/AU/Standalone; індустріальний стандарт
- **Платформа**: macOS first — машина розробки; Windows після валідації ядра
- **Продуктивність**: аналіз 3-хвилинної пісні — секунди, не хвилини; аналіз у фоновому потоці, UI не блокується
- **Сумісність**: VST3 SDK через JUCE; AU для Logic Pro; drag-and-drop MIDI має працювати в Ableton/FL/Logic
